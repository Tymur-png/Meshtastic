MESHTASTICDX-LR30 · EU868

АВТОНОМНЫЙ MESHTASTIC-МЕССЕНДЖЕР

Симулятор интерфейса прошивки: ESP32-S3 + DX-LR30 (SX1262) + TFT 320×240 + 6 кнопок. Телефон, Bluetooth и интернет не нужны — только LoRa mesh.

Управление (клавиатура тоже работает)

  • ↑↓←→ — навигация / курсор клавиатуры
  • Enter — OK (выбрать/подтвердить)
  • Esc — назад (долгое OK)
  • C или Tab — CHAT: чат ↔ клавиатура
  • В клавиатуре можно печатать физической клавиатурой

Демо-события

Что внутри

LoRa SX1262 · пакеты Meshtastic · mesh-маршрутизация · AES-PSK каналы · PKI для личных сообщений · ACK · телеметрия. Симулятор воспроизводит UI-слой прошивки 1:1.
